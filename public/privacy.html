Privacy

Survivor Fantasy Draft is a private family scoreboard. It is not a gambling service and it does not take payment.

Seats, custom leagues, and the bonus and trade switches stay on this device until you make an invite code. A code stores that league’s name, seats, picks, and chat so someone with the code can join and talk. A report of a chat message, and a note sent from Support, are stored so they can be reviewed. Blocked names stay on this device. There is still no account. Anyone with the code can open that one league and post under the name saved on their device.

Cast photos are used only to identify drafted players. The app does not ask for your location, contacts, camera, or microphone.

Crash and analytics reports stay off. Firebase is used only if the host adds their own config. Crashlytics runs on iOS and Android, not in the browser, and only after that config exists.

Erase everything from the Leagues screen. That removes the saved seat and any leagues you created on this device.

Disclaimer: this is a private scoreboard between friends. It is not Survivor, CBS, or a gambling service. The people who run the league are not liable for the buy-in, the prizes, a wrong or late score, a missed pick, or anything posted in the chat. You use it at your own risk.
