Survivor のファンタジードラフトです。ファンタジーフットボールと同じように遊びます。キャストをドラフトし、シーズンを追い、点数が最も低い人が勝ちます。非公開の家族リーグです。アプリ内での支払いはありません。

## 得点

最も低い点数が勝ちです。同点なら賞金を分けます。脱落は、その脱落の当事者だったときだけ得点になります。$10 の参加費はテーブルの間で、このアプリの外で精算します。アプリは代金を受け取りません。

表の順位名はシートと一致させ、英語のままにしています。

### 合流前

合流前の脱落を、順番どおりに数えます。

| Place | Points |
| --- | --- |
| 1st boot | 1 |
| 2nd | 2 |
| 3rd | 3 |
| 4th | 4 |
| 5th | 5 |
| 6th | 6 |

### 陪審

18 人の合流で得点します。優勝は 22 点です。

### ゼロになるもの

- **アイドルとアドバンテージ.** シート上はゼロです。ファイナル4の火起こし、または最終トライバルで使った場合を除きます。
- **棄権とメディバック.** ゼロです。トライバル中の棄権やメディバックも得点になりません。
- **Edge of Extinction.** 合流前に脱落して戻った人は、その脱落が 0 点で、その後は最終順位の場所で得点します。
- **最終トライバルの票.** 票そのものには点がありません。

最初の脱落は 1 点です。優勝は 22 点です。早い脱落はロスターを低く保つので、合計が最も低い人が勝ちます。

## ボード

`Survivor 51` が進行中のリーグです。23 席、フィジー。終了したシーズン 46–50 はシートに残ります。このテーブルでないときは、`Leagues` から `New league` を選んでください。

リーグを消すには、開いて `Delete league` を選びます。この端末に保存されたものをすべて消すには、`Leagues` 画面の `Erase this device` を使います。

あなたの席と、作成したリーグは、この端末に残ります。アカウントはありません。
