Ito ay pribadong talaan ng draft ng pamilya para sa Survivor. Inaayos ang ambag sa labas ng app.

Para burahin ang isang liga, buksan ito at piliin ang `Delete league`. Para burahin ang lahat ng naka-save sa device na ito, gamitin ang `Erase this device` sa screen na `Leagues`.

Kontakin ang nagpapatakbo ng inyong mesa, o [github.com/tanre77](https://github.com/tanre77).
